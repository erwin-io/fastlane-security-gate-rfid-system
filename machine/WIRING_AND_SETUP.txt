FASTLANE ONE-WAY ENTRANCE RFID GATE
WIRING AND SETUP - CURRENT FIRMWARE v2.5.2
ESP32-S3 + 1x ULN2003A + 2x TB6600 + 2x NEMA17 + RDM6300 +
2x VL53L0X + W5500 + MicroSD + DS3231 + WS2812B + Solenoid + Buzzer

IMPORTANT:
This replaces the stale v1.7.2 wiring guide in the 2026-10-07 export.
The current firmware uses FOUR limit switches, GPIO19 staff/config control,
server-decided RFID access, SoftI2C and updated motor timings.

===============================================================================
1. COMMON POWER / GROUND
===============================================================================

ESP32 logic GND, ULN2003A GND and peripheral grounds exchanging logic signals
must share a common reference ground.

Keep high-current motor phase and solenoid/load wiring away from:
- I2C SDA/SCL
- RFID UART signal
- limit switch signal pairs
- ESP32 reset/control wiring

Use the correct supply voltage for each exact module.
Do not power motors, solenoid or high-current buzzer directly from ESP32 GPIO.

===============================================================================
2. MOTOR CONTROL - ONE ULN2003A, TWO TB6600
===============================================================================

DRIVER #1 / LEFT
GPIO1 -> ULN IN1 -> OUT1 -> TB6600 #1 PUL-
GPIO2 -> ULN IN2 -> OUT2 -> TB6600 #1 DIR-
+5V   -> TB6600 #1 PUL+
+5V   -> TB6600 #1 DIR+
ENA+/ENA- -> NOT CONNECTED

DRIVER #2 / RIGHT
GPIO40 -> ULN IN3 -> OUT3 -> TB6600 #2 PUL-
GPIO41 -> ULN IN4 -> OUT4 -> TB6600 #2 DIR-
+5V    -> TB6600 #2 PUL+
+5V    -> TB6600 #2 DIR+
ENA+/ENA- -> NOT CONNECTED

ULN2003A VDD -> regulated +5V
ULN2003A GND -> common logic GND
ESP32 GND    -> same common logic GND

ESP32 HIGH -> ULN output sinks LOW -> TB6600 '-' active
ESP32 LOW  -> ULN output released

===============================================================================
3. NEMA17 MOTOR OUTPUT WIRING
===============================================================================

Machine connector reference:
Pin 1 = BLUE
Pin 2 = GREEN
Pin 3 = RED
Pin 4 = BLACK

BOTH MOTORS USE THE SAME WIRING:
TB6600 A+ -> BLACK -> Pin 4
TB6600 A- -> GREEN -> Pin 2
TB6600 B+ -> RED   -> Pin 3
TB6600 B- -> BLUE  -> Pin 1

Motor #2 opposite physical rotation is generated by its independent DIR signal:
TB6600_MOTOR2_OPPOSITE = True

For a replacement motor, verify coil pairs electrically/datasheet-wise instead of
assuming they match only by color.

===============================================================================
4. TB6600 MICROSTEP / CURRENT
===============================================================================

Firmware assumes:
full steps/rev = 200
microstep      = 1/8
pulses/rev     = 1600

Set BOTH TB6600s to the same 1/8 microstep mode using the switch table printed on
the exact installed drivers.

Current DIP switch combinations are hardware-model-specific. The v2.5.2 software
does not encode or validate the physical TB6600 current switch setting. Set the
current from the verified motor requirement and the exact driver label.

===============================================================================
7. LIMIT SWITCH WIRING PRACTICE
===============================================================================

Recommended for long/noisy wiring:
- twisted GPIO + GND pair
- route away from motor phases
- route away from solenoid/relay load wiring
- secure connectors/terminal blocks
- optional 4.7k-10k pull-up to 3.3V if required
- optional approximately 100 nF GPIO-to-GND only after validating response time

Do not pull an ESP32 GPIO up to 5V.

===============================================================================
8. MOTOR POWER
===============================================================================

Motor PSU + -> TB6600 #1 V+ and TB6600 #2 V+
Motor PSU - -> TB6600 #1 V- and TB6600 #2 V-

TB6600 #1 motor outputs -> Motor #1 only
TB6600 #2 motor outputs -> Motor #2 only

Do not reconnect both motors to one TB6600 output.

===============================================================================
9. SOLENOID RELAY
===============================================================================

GPIO15 -> relay control input

FIXED ACTIVE-LOW:
GPIO15 HIGH = relay OFF = solenoid unpowered = LOCKED
GPIO15 LOW  = relay ON  = solenoid powered   = UNLOCKED

12V load example:
12V PSU + -> relay COM
relay NO  -> solenoid +
solenoid - -> 12V PSU GND

Use suitable inductive-load suppression.
For an appropriate DC flyback diode:
stripe/cathode -> solenoid +
anode          -> solenoid -

10. RDM6300 / MD0016 125 kHz RFID
===============================================================================

RDM6300 VCC -> module-rated supply

===============================================================================
11. GPIO19 STAFF / CONFIG BUTTON
===============================================================================

GPIO19 -> push button -> GND

Current timing:
debounce = 50 ms
staff open threshold = 1500 ms
configuration mode = 5000 ms

Behavior:
release before 1.5 s -> no action
reach 1.5 s          -> armed chirp
release 1.5-<5 s     -> STAFF OPEN
hold to 5 s          -> toggle CONFIGURATION MODE

Mount this as a staff-only control.

===============================================================================
19. CONFIGURATION MODE ACCESS
===============================================================================

Normal boot: Wi-Fi AP and config web are OFF.

To enable:
1. Gate stationary/no active passage.
2. Hold GPIO19 for 5 seconds.
3. Connect to FASTLANE-GATE-01.
4. Default password: Fastlane123
5. Browse http://192.168.4.1/.

While active:
RFID disabled
ToF paused except requested background capture
motors disabled
solenoid locked
LED red X

Hold GPIO19 5 seconds again to exit. The gate re-homes BOTH CLOSE switches.

===============================================================================
21. FIRST POWER / COMMISSIONING TEST
===============================================================================

1. Power with mechanism in a safe condition.
2. Confirm boot prints solenoid LOCKED.
3. Verify four limit GPIOs manually.
4. Verify motor OPEN/CLOSE directions.
5. Verify each motor stops on its own switch.
6. Verify both CLOSE switches are found at boot.
7. Verify ToF empty lane = NO_PRESENCE.
8. Verify a person produces PRESENCE and blocks RFID.
9. Verify W5500 link/API health.
10. Verify RFID shows correct 10-digit decimal ID.
11. Verify DENIED/timeout never opens.
12. Verify GRANTED performs full open/pass/close cycle.
