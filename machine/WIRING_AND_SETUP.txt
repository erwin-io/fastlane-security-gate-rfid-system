5. MASTER MECHANICAL LIMIT SWITCHES - LEFT / MOTOR #1
============================================================

CLOSED / LOCK LIMIT

ESP32-S3 GPIO39
-> one terminal of CLOSED mechanical switch

other switch terminal
-> GND


OPEN / UNLOCK LIMIT

ESP32-S3 GPIO42
-> one terminal of OPEN mechanical switch

other switch terminal
-> GND

Firmware uses internal pull-up:
Switch released = HIGH
Switch pressed  = LOW

GATE_LIMIT_ACTIVE_LOW = True
GATE_LIMIT_DEBOUNCE_MS = 5
GATE_REQUIRE_CLOSED_LIMIT_FOR_OPEN = False
GATE_LIMIT_AUTO_ARM = True

Startup / bench-test behavior:
- If neither endpoint switch is active at boot, RFID operation is NOT blocked.
- The gate keeps normal open-loop angle travel until either LEFT switch is seen.
- After a LEFT endpoint switch is observed active, endpoint feedback auto-arms.
- Strict CLOSED-limit-before-RFID behavior can be enabled later by setting
  GATE_REQUIRE_CLOSED_LIMIT_FOR_OPEN = True after hardware verification.

Endpoint seek settings:
GATE_LIMIT_ENDPOINT_SEEK_ENABLED = True
GATE_LIMIT_ENDPOINT_SEEK_DEGREES = 3.0
GATE_LIMIT_ENDPOINT_SEEK_DELAY_US = 4000

IMPORTANT:
The CLOSED switch is intentionally ignored during the special latch-release CLOSE
preload because the gate is already sitting at the closed mechanical endpoint.

During normal OPEN/CLOSE travel, the LEFT switch stops Motor #1 independently.
Motor #2 continues its own calculated remaining steps.

If the expected switch is not reached by the normal calculated endpoint, Motor #1
alone moves up to 3 additional degrees slowly while searching for the switch.
If the switch still does not activate, firmware enters ERROR.

If both OPEN and CLOSED switches are active simultaneously, treat it as a wiring
or mechanical fault.

Recommended for long/noisy switch wiring:
- twisted GPIO + GND pair
- route away from NEMA phase wires and solenoid wires
- optional external 4.7k-10k pull-up from GPIO to 3.3V
- optional ~100nF capacitor from GPIO to GND

============================================================
16. LATCH-RELEASE SEQUENCE
============================================================

RFID GRANTED
-> solenoid unlocks immediately
-> wait 1000 ms default
-> both motors perform slow 3-degree CLOSE-direction preload
-> preload half-pulse delay = 6500 us
-> hold preload / solenoid released = 350 ms
-> software position re-anchors to CLOSED
-> both motors start normal fast OPEN travel

This special preload intentionally ignores the CLOSED limit switch.

============================================================
17. NORMAL ENDPOINT SEQUENCE
============================================================

OPEN:
- Motor #1 and Motor #2 start together.
- Their physical shaft directions are opposite.
- Their logical gate direction is the same: OPEN.
- LEFT OPEN switch stops Motor #1 only.
- Motor #2 finishes its own calculated remaining pulses.
- If LEFT OPEN switch was missed, Motor #1-only endpoint seek runs.

CLOSE:
- VL53L0X must report safe/clear.
- Motor #1 and Motor #2 close together.
- LEFT CLOSED switch stops Motor #1 only.
- Motor #2 finishes its own calculated remaining pulses.
- If LEFT CLOSED switch was missed, Motor #1-only endpoint seek runs.
- Solenoid is forced to LOCKED/OFF at the completed CLOSED endpoint.
